VideoRoll —— 便携式视频播放列表小工具
========================================

一个绿色便携的小窗口程序：保存视频播放列表，双击用本地 mpv 播放器播放，
并且把“软件里的列表”当作播放列表（自动绕过 autoload.lua 脚本）。


【直接使用（无需安装任何东西）】
1. 把整个 "VideoRoll" 文件夹复制到任意位置（绿色便携）。
2. 双击运行 VideoRoll.exe。
3. 首次使用：点右上角“设置”按钮，选择你的 mpv.exe（也可以直接在 config.json
   里填 MpvPath，或在设置里配置额外的 mpv 启动参数）。
4. 把视频文件夹、单个视频文件或 .m3u / .m3u8 播放列表拖进窗口，即自动导入。
5. 双击列表中某一项 → 用 mpv 播放，且整个软件列表就是 mpv 的播放列表。


【操作说明】
- 拖拽文件夹 / 视频文件 / .m3u8 播放列表到窗口：导入（默认递归搜索子文件夹，自动跳过符号链接防止成环）。
- 双击（或按回车）：从该项开始播放，播放顺序 = 软件列表当前顺序。
- Ctrl + 点击 / Shift + 点击：多选；支持列表内拖拽调整顺序。
- Ctrl + ↑ / Ctrl + ↓：上移 / 下移选中项。
- Ctrl + A：全选；Ctrl + Z / Ctrl + Y：撤销 / 重做。
- Ctrl + L：快速聚焦过滤框（按 Enter 跳到列表首项，Esc 清空过滤）。
- Ctrl + F：在资源管理器中查看选中文件（文件已失效时自动尝试打开原所在目录）。
- Del：从列表中移除（只删列表项，绝不删除真实文件）。
- 右键菜单：播放 / 仅播放当前过滤结果（过滤生效时显示）/ 打开文件所在目录 / 复制路径 / 移除 / 添加 / 导出播放列表 / 清空。
- 顶部按钮：添加、排序（按文件名自然排序 / 按路径自然排序 / 反转顺序）、随机打乱、清空列表、清理已失效、设置。


【数据保存在哪】
- config.json   —— 设置（mpv 路径、扩展名、是否递归、额外参数、窗口位置）
- playlist.json —— 播放列表（原子写入并保留 .bak 备份，损坏时自动恢复）
- error.log     —— 未处理异常崩溃日志（仅发生异常时生成）
均保存在 VideoRoll.exe 同目录，随文件夹一起携带。


【自行编译】
需要 .NET 9 SDK。在源码目录执行：

    dotnet publish -c Release
